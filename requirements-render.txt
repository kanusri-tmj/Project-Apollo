# Runtime-only dependencies for the deployed Flask service (see render.yaml).
#
# Two things are deliberate here:
#
# 1. This file is much narrower than requirements.txt. Nothing on the request
#    path imports matplotlib, seaborn, streamlit, jupyter or pytest
#    (`app/flask_app.py` -> src.config / src.explain / src.predict
#                     -> src.preprocessing), so leaving them out keeps the
#    Render build small and fast and removes a whole class of build failures.
#
# 2. The versions are pinned *exactly* to the stack the test suite passes
#    against locally (Python 3.14.3, see .python-version). Ranges would let a
#    fresh deploy resolve to a different pandas/scipy than the one that was
#    tested; a deploy is the one place you want the bytes you validated.
#    To upgrade: bump the pin, run `python -m pytest`, then redeploy.
#
# Use requirements.txt for local development, training, the notebook and the
# Streamlit UI.
